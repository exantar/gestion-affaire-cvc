Le proprietaire du projet autorise Codex a publier directement les mises a jour de ce site vers le depot GitHub `exantar/gestion-affaire-cvc` afin de declencher le deploiement Render.

Cette autorisation concerne les evolutions demandees pour le site de gestion d'affaires CVC. Elle ne couvre pas l'ajout de secrets, de cles privees ou de donnees sensibles dans le depot.
