# Gestion d'affaire CVC

Application web statique pour piloter des chantiers CVC :

- suivi des chantiers, achats, FAE et heures ;
- Go / No-Go avec export Excel ;
- Todo List Lean Construction ;
- espace technicien avec saisie d'heures et planning hebdomadaire.

## Lancer le site

Ouvrir `index.html` dans un navigateur.

## Base de données

Le fichier `supabase-config.js` contient la configuration Supabase utilisée par le site.
Le schéma de base est dans `supabase-schema.sql`.
